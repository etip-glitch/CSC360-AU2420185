# reflection points (13/08/2026)
**maven setup**
1. pom.xml defines the project (groupId, artifactId, version, Java version)
2. standard folder structure: src/main/java holds the code
3. mvn compile → checks/builds code
4. mvn package → packages it into a jar

**java program**
1. used swing (JFrame, JPanel, Graphics) to draw a square visually
2. paintComponent(Graphics g) is where drawing happens
3. g.fillRect(x, y, width, height) draws the square (equal width and height)

**git basics**
1. git init → starts a repo
2. git add . → stages files
3. git commit -m "message" → saves a snapshot
4. git push -u origin main → uploads to GitHub

**github notes**
1. GitHub shows code only, not program output
2. to show visual output, add a screenshot to the repo and link it in README.md
3. files can be uploaded directly via GitHub's website too (Add file → Upload files)
